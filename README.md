# CONSTRU LAR — site oficial
Site estático (HTML, CSS, JS) pronto para GitHub Pages.

## Antes de publicar
1. **Logotipo:** salve o arquivo original em `assets/logo/logo-constru-lar.png` (sem editar).
2. **Produtos:** edite `js/products.js` (adicionar/remover/atualizar). Hoje os dados são DEMONSTRATIVOS.
   Fotos: coloque em `assets/products/` e preencha `imagem: "assets/products/arquivo.jpg"`.
3. **WhatsApp, Instagram e mensagem:** `js/config.js`.

## Publicar no GitHub Pages
Envie os arquivos para um repositório → Settings → Pages → Deploy from a branch → `main` / `(root)`.
Todos os caminhos são relativos, então funciona em `usuario.github.io/nome-do-repositorio/`.
